## Findings for a spec revision (1.1.2)

- §9.19.3 has no reason for `REWORK_PLANNING -> FAILED` ("rework limit
  reached", §15). The vocabulary module maps it to `FAILURE_ESTABLISHED`; the
  spec table should say so.
- `AuditLog.append` does not yet reject event types outside §9.19.2, because
  existing HK-001 unit tests use free-form types. HK-003 should make `append`
  strict and update those tests.

## Known limitations

- The monitor does not verify the hash chain; it only warns about gaps.
- Page tests require Node Playwright and Chromium; without them they are
  skipped as `BLOCKED`, and completion cannot be claimed.
- Fonts still load from Google Fonts by default; the page falls back to system
  fonts offline, and the links can be deleted (documented).
